# Feature request: Unified plan comparison page across app and web

**Requested by:** Plans & Pricing product team
**Brand:** Nimbus Wireless
**Platforms:** app and web

## Background
Today the app shows plans as a carousel of cards while the website has a comparison table, and the two show different plan attributes. Customers who start on one surface and finish on the other get confused. Analytics cannot compare the two funnels because the events are named differently on each platform.

## What we want
- A single plan comparison page with the same layout and plan attributes on app and web.
- Customers must be able to select up to 3 plans to compare side by side.
- Show monthly price, data allowance, hotspot allowance and included perks for each plan.
- Customers must be able to filter plans by number of lines.
- Selecting a plan must take the customer to the existing plan change checkout.
- Plan content must come from the Plan Catalog API so app and web never disagree.
- The page should be fast and look modern, with better accessibility.

## Success
Increase plan change conversion from the comparison page and get one funnel for app and web. Use the same event names on both platforms.

## Out of scope
- Changing plan prices or creating new plans.
- Prepaid plans (Nimbus Prepaid will follow later).

## Notes
We'd like to run this as an experiment against the current pages. Not decided yet whether logged-out visitors can see the page.
